# Pre-extracted ICCSD structured data (raw provenance)

Imported from the ICCSDAdvocacy repository as source material for this project.

- Source repo: https://github.com/michael480th/ICCSDAdvocacy
- Source commit: 710b19c59b53b2ddd79066c516b6a5cbeacf5c18 (2026-06-06)
- Imported on: 2026-06-06
- These are public records (audited ACFRs and Iowa state filings). This project
  is unofficial and not affiliated with ICCSD or any district.

Already-structured, source-cited extractions produced by the ICCSDAdvocacy
project. Imported here as **raw provenance / a head start** — NOT yet wired into
this project's normalized tables. They will be re-derived or mapped into
`data/normalized/` in a later phase, with their own source links.

- `district-extractions/Iowa_City_CSD.csv` — per-year audit extraction
  (cash & investments, GF revenue/expenditure/fund balance, GO & SAVE debt,
  solvency/operating margin, findings) FY2020–FY2023. Pipe-delimited.
- `notes-extractions/Iowa_City_CSD.csv` — balance-sheet & forward-commitment
  data from audit notes (net position, construction commitments, future debt
  service) FY2020–FY2023. Pipe-delimited.
- `dom/` — the DOM-derived per-district CSVs (UAB, AEA, valuations, levies,
  at-risk, enrollment) with the source repo's own README describing columns.
