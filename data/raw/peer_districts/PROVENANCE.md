# Peer-district audited ACFRs (benchmark context)

Imported from the ICCSDAdvocacy repository as source material for this project.

- Source repo: https://github.com/michael480th/ICCSDAdvocacy
- Source commit: 710b19c59b53b2ddd79066c516b6a5cbeacf5c18 (2026-06-06)
- Imported on: 2026-06-06
- These are public records (audited ACFRs and Iowa state filings). This project
  is unofficial and not affiliated with ICCSD or any district.

Audited ACFRs FY2020–FY2025 for 14 other large Iowa districts (Ankeny, Burlington,
Cedar Rapids, College/Prairie, Davenport, Des Moines, Dubuque, Johnston, Linn-Mar,
Muscatine, Pleasant Valley, Waterloo, Waukee, West Des Moines).

These are **benchmark/comparison context**, not inputs to the ICCSD cash forecast.
Kept separate from ICCSD's own documents so the forecast pipeline never confuses
peer data with Iowa City figures.

Original location in source repo: `auditreports/<District> CSD-<year>.pdf`.
