# Iowa DOM / DE statewide source workbooks

Imported from the ICCSDAdvocacy repository as source material for this project.

- Source repo: https://github.com/michael480th/ICCSDAdvocacy
- Source commit: 710b19c59b53b2ddd79066c516b6a5cbeacf5c18 (2026-06-06)
- Imported on: 2026-06-06
- These are public records (audited ACFRs and Iowa state filings). This project
  is unofficial and not affiliated with ICCSD or any district.

Statewide Iowa Department of Management / Department of Education workbooks. Each
file covers ALL Iowa districts (including Iowa City); the relevant rows are
filtered downstream. These are **state-computed and unaudited** — they exist even
when a district's audit is missing.

Per-folder origin URLs are preserved in each `source.txt`. Contents:

- `UAB/` — Unspent Authorized Budget (spending authority; Iowa's #1 health metric)
- `AEA/` — AEA enrollment & cost detail/summary (flow-through, enrollment)
- `PropertyValuation/` — assessed & taxable valuations by class
- `PropertyTaxRateFiles/` — historical school tax rates
- `FinalCashReserveLevies/` — cash-reserve levy (solvency lever)
- `AtRiskFormula/` — at-risk supplementary weighting (spending-authority driver)
- `AidandLevyTaxCertification/` — Aid & Levy tax-certification program summary
